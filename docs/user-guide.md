# 使用指南

本文介绍桌面应用中的主要用户功能。AI 模型、API Key 和操作审查模型的配置方法见[模型与配置](configuration.md)；可调用工具的完整目录见[Skills 说明](skills.md)。

## 聊天与界面

- 新会话欢迎页会根据配置状态显示“配置 AI”或“调整设置”，并提供“解释代码”“整理网页”“查看项目”提问示例。点击示例只会将文字追加到输入框，不会自动发送。
- 输入区提示 **Enter 发送、Shift+Enter 换行、右键复制消息**；代码块可通过右键菜单单独复制。
- 等待回复时仍可继续发送消息，请求按顺序处理；“停止”可取消当前请求。请求失败时会显示错误和“重试”按钮。
- 上下文过长时，发送给模型的较早对话会按约 32,000 字符自动裁剪；界面中保存的完整历史不受影响。
- 欢迎页和输入区下方的“使用指南”提供离线帮助；设置窗口的“配置说明”可直接打开模型配置章节。阅读帮助不会发起模型请求，也不需要 API Key。

## 网页、图片与视频

### 网页阅读

在消息中粘贴最多 3 个公开 HTTP(S) 网页链接，应用会读取 HTML 正文并提取图片候选。每页最多读取 1 MB，向模型提供最多 12,000 个正文字符，并提取最多 20 个图片 URL。网页阅读不支持需要登录、JavaScript 渲染或非 HTML 的页面，也不提供一般网页搜索。

明确要求发送网页图片时，AI 可从本轮网页候选中选择图片并显示预览；候选之外的 URL 不可通过该功能下载。对于 `bilibili.com` 的视频链接（`/video/`、`/short-video/` 路径或 `?bvid=` 参数），应用会通过 Bilibili 公开 API 获取标题、UP 主、分 P、标签、简介和封面；`b23.tv` 短链接及 UP 主个人空间页不支持。

遇到 Minecraft 知识问题时，AI 会搜索中文 Minecraft Wiki，并依据条目回答、提供来源链接。学术论文、作者或期刊问题可搜索中国知网公开检索页面，返回公开可见的题名和链接；知网可能要求安全验证，摘要或全文可能需要账号或机构权限。两者均为在线检索，不会下载整站或建立本地数据库。

### 附件与媒体

“添加图片/视频”支持 JPG、JPEG、PNG、GIF、WebP 图片及 MP4、MOV、AVI、MKV、WebM、M4V 视频。单张图片最大 10 MB，单个视频最大 200 MB。视频在本机抽取最多 16 个均匀分布的画面帧，不包含声音或连续动作信息。主模型和服务端须支持图像输入；若主模型明确无法分析媒体，应用可按配置顺序询问子代理能否直接查看，子代理只为该次请求临时创建。

明确要求生成图片或视频时，AI 可调用相应工具。图片会显示预览；视频可用系统默认播放器打开。生成文件保存在 `%LOCALAPPDATA%\Prana\media`。当前视频生成请求时长为 4 秒：普通 OpenAI 风格服务使用横向 1280×720，Agnes Video 2.5 使用 720P、16:9 文生视频参数。生成可能产生额外 API 费用。

明确要求发送本机媒体时，`send_local_media` 会打开文件选择器。用户选中的文件只在聊天中展示，不上传给 AI。

网页内容、媒体和对话上下文可能会发送给所配置的 AI 服务；不要提交不应由该服务处理的敏感信息。

## QQ 音乐

明确要求控制桌面 QQ 音乐时，AI 可执行播放/暂停、上一首/下一首、停止、音量调节、静音或搜索。QQ 音乐必须已在 Windows 上运行，应用不会自动启动它。

搜索只展示搜索结果，不自动播放；“搜索并播放”会选择搜索建议并尝试播放，可通过 `result_index` 指定第 1–10 条建议（默认第 1 条）。应用会通过窗口标题检查播放结果；无法确认目标歌曲开始播放时会明确报错。

## Minecraft 游戏陪玩

明确要求陪玩 Minecraft Java 版时，Prana 会先探测本机 `25565–25569` 端口；如果用户提供了其他本机端口，也会探测该端口。明确说明是本地服务器并提供端口时可使用 `127.0.0.1`；地址或端口不明确时会询问，不会猜测外部地址。每次加入服务器前，操作审查模型都会审查目标；未配置审查模型或审查拒绝时不会启动游戏本体。版本使用用户提供或服务器探测到的版本，否则由客户端自动检测。

加入后，游戏大脑会开始自主游玩，并约每 30 秒根据环境状态继续规划；游戏聊天也会触发额外决策。可用动作包括扫描附近环境、跟随玩家、公屏/私聊、查看背包、装备、合成、移动、采矿、食用或使用物品、与方块或实体交互、放置方块和攻击。顶部的游戏状态按钮可结束会话，退出程序也会清理游戏本体进程。

自主游玩依赖模型工具调用，不代表已验证全程通关。没有专用的生存进度、要塞定位或末影龙战斗控制器；远距离探索、材料不足或危险时可能需要用户指示。附近扫描半径最多 64 格，采矿和攻击仍受本地寻路与 Mineflayer 能力限制。

游戏大脑只获得 Minecraft 陪玩动作，不具备文件、终端或系统工具。游戏聊天显示为独立、静音的会话卡片，不加入主模型对话历史；空闲时会按自主行动周期调用模型，连续游戏聊天事件会合并后触发回复。

本功能需要 Windows 上已安装 Node.js 20 或更新版本。首次加入时，Prana 将随应用分发的 Node 工程复制到 `%LOCALAPPDATA%\Prana\mc_body` 并运行 `npm ci` 安装依赖。仅支持 vanilla 离线/LAN 服务器；启用 `online-mode=true` 的正版验证服务器和 NeoForge 等模组服务器不在一期支持范围内。Minecraft 原版离线服务器不能显示由客户端单方面设置的自定义皮肤；皮肤文件会被校验并复制到 `%LOCALAPPDATA%\Prana\assets\普拉娜.png`，但不保证游戏内可见。支持皮肤插件的服务器可在设置中填写相应命令。

发现可复用的游戏操作流程时，游戏大脑可以创建 MC 技能。每个新技能均须经操作审查模型审核后保存；技能采用受限的 `run(api)` 形式，只允许最多 16 个顺序白名单动作和常量参数，不执行任意 Python。详情见[Skills 说明](skills.md#minecraft-自定义技能)。

## 桌面键鼠控制

明确要求查看屏幕或操作现有窗口时，AI 会先请求桌面控制。应用弹出授权窗口，用户点“允许”后，操作审查模型还会审查用户请求和操作计划；两者都通过后，当前会话才获得授权。

授权后可读取屏幕/窗口信息、激活已打开窗口、执行鼠标和键盘操作，并截取前台窗口、指定窗口或全屏。截图会缩放压缩后随本轮请求发送给模型，不保存截图文件；截图可能包含密码或聊天记录，请只在信任当前 AI 服务时授权。主模型须支持图像输入才能分析截图。

授权仅在当前会话有效，不写入磁盘；清空对话、删除会话、退出程序或点击“撤销”后失效。第一版不会自动启动新程序，也不提供隐藏桌面或虚拟机隔离。按住 Esc 1.5 秒可紧急停止；`Win+L`、`Ctrl+Alt+Delete`、`Win+R`、`Win+S/Q`、`Win+E` 等组合键会被拦截。

## 多模型头脑风暴

主模型可在复杂问题回答前调用 `start_brainstorm`，召集自己、已勾选“参与头脑风暴”的子代理和链接提供商模型进行多轮讨论。默认 10 轮，可在设置中调整为 1–50；每位参与者每轮有一次发言机会，也可以跳过。参与者最多 12 位（含主模型）。

讨论后，主模型只收到精简总结和关键分歧；完整记录保存在独立头脑风暴子会话中，可从聊天中的卡片打开。参与者各有独立只读子会话，不能继续对话。默认 10 轮会产生多次 API 调用，可能产生额外费用；只有主模型判断需要时才会启动。

头脑风暴会把当前请求和最近对话历史发送给所有参与者。主聊天和头脑风暴会话以明文保存在本机；请勿在讨论中包含不应交给这些服务处理的敏感内容。API Key 使用 Windows DPAPI 加密，详情见[模型与配置](configuration.md#本地数据与隐私)。
